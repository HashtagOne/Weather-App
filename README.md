# Weather App
A real-time weather app built with vanilla HTML, CSS, and JavaScript. Fetches live data from the OpenWeatherMap API and displays current conditions for any searched city in a Frutiger Aero-inspired frosted glass interface.

## Features

Search weather by city name
Displays temperature, weather description, humidity, and wind speed
Dynamic weather icon from OpenWeatherMap
Error handling for invalid city names
Search via button click or Enter key
Smooth fade-up animation on results
Frutiger Aero light mode design with frosted glass card

## Concepts Used

Fetch API and Promise chains (.then / .catch)
Consuming and navigating a real REST API JSON response
DOM manipulation and dynamic content rendering
CSS glassmorphism (backdrop-filter, rgba backgrounds)
Event listeners including keydown for Enter key support
Input validation and conditional rendering
CSS animations and transitions

## Tech Stack
HTML5
CSS3
JavaScript (ES6)
OpenWeatherMap API
